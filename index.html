Unit 2　冠詞 Articles ＆ 名詞 Nouns

1不定冠詞 a / an

  • 放在單數可數名詞前面：a pen, an apple
  • a / an 看發音，不看字母：子音發音用 a、母音發音用 an。
    a university（u 唸 /ju/＝子音）　an hour（h 不發音＝母音）
  • 什麼時候用？
    ① 說不特定的人事物：There's a man at the door.門口有一個男人。
    ② 說職業：She's a teacher.她是老師。

2定冠詞 the：什麼時候要加？

the 可以放在不可數名詞、單數／複數可數名詞前：the milk, the pen, the pens

✅ 要用 the

規則例句
特定的、獨一無二的The man at the door is my uncle. / The sun rises in the east.
海、洋、河、沙漠the Mediterranean, the Atlantic, the Amazon, the Sahara
群島、山脈、複數／縮寫國名the Canary Islands, the Himalayas, the USA
姓氏（指全家人）the Smiths（史密斯一家）
民族（指全體國民）the Greeks　but Fiona is Italian.（指個人不加）
play ＋ 樂器He plays the piano.
旅館、電影院、報紙the Hilton Hotel, the Rex Cinema, the Times
方位in the east
最高級Tom is the tallest boy in this class.

❌ 不加 the（零冠詞 –）

規則例句
人名、城市、島、湖、單數國家、街道、洲、國籍That's Maria. She comes from Spain.
學科、運動History is interesting. We love football.
泛指的不可數／複數名詞I like coffee. Cats like milk.
三餐We have lunch at 1:30.
hospital, home, school, church, bed, work, prison（用在本來的功能）The boys are at school.
but The boys visited their uncle at the hospital.
💡 速記：河、海、洋、沙漠、山脈、群島、方位、最高級 → the；人名、城市、湖、單座山、單數國名、洲、街道、學科、運動、三餐 → 不加。

3名詞：可數 ＆ 不可數

可數名詞變複數

規則例字
一般 ＋spen → pens
字尾 s, x, ch, sh ＋esbox → boxes, watch → watches, brush → brushes, glass → glasses
子音 ＋ o → ＋estomato → tomatoes　but piano → pianos, radio → radios
子音 ＋ y → 去 y 加 iesbaby → babies　but 母音＋y 直接加 s：toy → toys
f / fe → vesknife → knives, leaf → leaves　but roof → roofs

不可數名詞

  • 不能數，只有單數，前面不能加 a / an 或數字：milk, water, butter, wood, glass（玻璃）, money, time
  • 要說數量，用量詞 ＋ of：a carton of milk, a loaf / slice of bread
    量詞：bottle, piece, loaf, slice, carton, cup, glass, packet, kilo, litre, box, bar, bowl
Unit 3　Some / Any / No / Every ＆ 數量詞

0先學會兩個分類（超重要！）

Unit 3 的字選錯，幾乎都是因為沒先看清楚這兩件事：① 名詞是哪一種？ ② 句子是哪一種？

① 名詞三種長相

種類怎麼判斷例子
單數可數前面能加 a / ana pen, an apple, a student
複數可數有 s，能放 two、threepens, apples, students
不可數不能加 s、不能數 twowater, milk, sugar, money, time, homework
💡 偷懶測試：「two ＋ 這個字」聽起來對嗎？two apples 對 → 可數；two waters 怪怪的 → 不可數。

② 句子四種心情

😀 肯定句　🚫 否定句（有 not / n't）　❓ 疑問句　🎁 邀請／客氣請求

1some / any / no：「有」或「沒有」

這三個字後面接不可數名詞或複數名詞（some milk, some books；✗ some book）。

句子心情用哪個字例句
😀 肯定句someI have some apples.
🚫 否定句any（not ＋ any）I don't have any apples.
❓ 疑問句anyDo you have any apples?
🎁 邀請／請求someWould you like some cake? / Can I have some water?
😀 句子是肯定，意思卻是「沒有」noI have no apples.（＝ I don't have any apples.）
💡 口訣：肯定 some，否定問句 any，no 自己就是「不」。
⚠️ no ＝ not any，兩個「不」不能疊在一起：✗ I don't have no apples.　✓ I don't have any apples. / I have no apples.

some / any 後面的名詞可以省略（當代名詞）：Is there any juice? No, there isn't any.

2every：「每一個」

  • every 後面接單數名詞，動詞也用單數。
  • Every student has a bag.
✗ Every students have a bag.✓ Every student has a bag.
💡 把 every 想成「一個一個地看」：每次只看一個學生，所以名詞沒有 s、動詞要加 s（has / likes）。

常見搭配：every day, every morning, every Monday, every child

3複合字：someone、anything、nowhere…

公式：some / any / no / every ＋ one（人）／ body（人）／ thing（東西）／ where（地方）

＋ one / body（人）＋ thing（東西）＋ where（地方）
somesomeone / somebodysomethingsomewhere
anyanyone / anybodyanythinganywhere
nono one / nobodynothingnowhere
everyeveryone / everybodyeverythingeverywhere
  • 用法和 some / any / no / every 一模一樣：肯定句 some 系列、否定／疑問句 any 系列、no 系列自己就是否定。
    I want something to eat.　I can't find my keys anywhere.　Is there anyone at home?
  • 後面不接名詞（它們已經包含「人／東西／地方」了）：✗ something food　✓ something to eat
  • 動詞永遠用單數：Everyone is here. Nothing is in the box.
⚠️ nothing / nobody / nowhere 本身就是否定：✗ I don't have nothing.　✓ I have nothing. / I don't have anything.

4much / many / a lot of / a little / a few：「多」與「少」

數得出來（複數可數）
chairs, eggs, books		數不出來（不可數）
water, sugar, money
很多（問句／否定句）many
Are there many chairs? There aren't many chairs.		much
Is there much sugar? There isn't much sugar.
很多（肯定句）a lot of（可數、不可數都能用）
There are a lot of chairs. There's a lot of sugar.
一些、一點點（肯定句）a few
There are a few chairs.		a little
There's a little sugar.
💡 口訣：數得出來 → many / a few；數不出來 → much / a little；a lot of 兩邊都可以。
⚠️ much / many 平常不放在肯定句。✗ I have much homework.　✓ I have a lot of homework.

後面的名詞也可以省略（當代名詞）：How much money have you got? I haven't got much. / Are there many eggs? No, only a few.
口語可用 lots of（代名詞：lots、a lot）。

5How much? / How many?

問句問什麼例句
How many ＋ 複數可數名詞問「幾個」How many books have we got?
How much ＋ 不可數名詞問「多少量」How much milk is there in the fridge?
How much is ...問「價錢」How much is this shirt?

🚨 5 大地雷

  • ✗ There isn't no milk. → ✓ There isn't any milk.（not 和 no 不能疊）
  • ✗ Every students have… → ✓ Every student has…
  • ✗ I have many friends.（肯定句）→ ✓ I have a lot of friends.
  • ✗ Would you like any tea?（邀請）→ ✓ Would you like some tea?
  • ✗ I don't know nothing. → ✓ I don't know anything.
